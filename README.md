# Almighty Tuition Centre

Single-page React + Vite website for Almighty Tuition Centre, Tirunelveli.

## Included
- Royal Blue academic visual identity
- Fixed side navigation on desktop
- Smooth-scroll section navigation
- Mobile hamburger navigation
- Responsive sections for educator, courses, teaching approach, learning modes and enquiry
- Physics-inspired visual elements without requiring photos
- Enquiry form that prepares a WhatsApp message for the centre
- Phone and email contact links

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
